# **My Linux Dotfiles**
This is my current linux dotfiles for a minimalistic hyprland setup.

I've included installation instructions and troubleshooting tips that helped me when setting all of this up for the first time.
Please check the notes on the relevant section if you need any help.

Wallpapers are in dotfiles/Pictures
Files are in dotfiles/.config

## Matuwall & Matugen
<details>
<summary>Click to expand</summary>
  
This features a wallpaper selector and automatic theme changer upon changing the background.
The colour themes are generated by Matugen, and the wallpaper selector is generated by Matuwall.
Default keybind is Windows/Command + F (can be changed in hypr/Config/binds.lua).
You can also mess around with the script to generate more/less vibrant colours inside the hook in matuwall/config.toml by selecting a different value in --type (at the bottom of the file), or the vibrancy inside matugen/config.toml

![Matuwall](Screenshots/wallpaper_switcher.png)

</details>

<details>
<summary>Click to expand</summary>

## wlogout
<details>
<summary>Click to expand</summary>

Install wlogout with AUR (e.g. yay -S wlogout)
In order for the sizing to work, the script requires a few dependencies.
These include: awk, jq, procps-ng, hyprland, wlogout (check ALL of these are installed)
You can also set the size manually if you do not want to install any of these inside the script by specifying numeric values for -T and -B
Default keybind to bring it up is Windows/Command + Del (can be changed in hypr/Config/binds.lua)

<details>

## hyprland & other
<details>
<summary>Click to expand</summary>

Default terminal = fish with Kitty.
To install fish use (sudo pacman -S fish)
And then set it as default with (chsh -s /usr/bin/fish)
You can copy the fish config file
You can change what it displays on opening new terminal inside the fish/config.fish file. (default I set is fastfetch - use (sudo pacman -S fastfetch) to install)

Starship.toml is the icons on the fish terminal.
You can style the colours for this, I have not got round to it yet.

For the clock in terminal, I used tty-clock -c [centers it] - C [0-9 (this does the colour)]
e.g. tty-clock -c -C 1
Install with AUR (yay -S tty-clock)

For the rain I used terminal-rain (use terminal-rain -h for options)
Install with AUR (yay -S terminal-rain)
